# Название проекта
Проект решает несколько задач: маскировку номера карты и банковского счёта, преобразование даты формата 
"2024-03-11T02:26:18.671407" в формат "11.03.2024", фильтр списка дат по заданной части даты, сортировка дат;
вывод трансакций по заданному параметру, вывод типа произведенных трансакций, генерация номеров карт в заданном диапазоне.

## Тестирование
Наш проект покрыт тестами Pytest. Покрытие 80 %. При тестировании использованы различные 
варианты входных данных, фикстуры и параметризация. Создан файл confest, содержащий входные 
и выходные данные для тестов кода. В тестах отработаны заданные в функциях кода ислючения, ошибки.
